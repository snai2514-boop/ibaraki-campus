# 手机同步诊断

同步诊断自动写入应用私有目录 `noBackupFilesDir/sync-diagnostics`，不需要 USB 或电脑持续连接。应用重启后保留；清除应用数据或卸载会删除日志。两个轮转文件合计最多约 512 KiB，旧记录会按容量淘汰。

在「设置 → 导出同步诊断日志」导出文本文件。Android 10 及以上保存到 `Download/CampusAssistant`，稍后可从文件管理分享或连接电脑读取；旧版 Android 使用系统分享。导出在工作线程执行，包含之前进程的记录和本次同步记录。开启反馈中的日志选项时，仅附加最近 15,000 字符的诊断记录。

记录内容：时间、应用版本、随机同步会话号、步骤、耗时、页面可读取状态、是否出现登录控件、导航是否匹配、解析异常类型、网络错误代码和步骤结果。不会记录学号、姓名、密码、Cookie、认证 URL、网页正文或成绩明细。日志不会自动上传。

连接电脑时，可用 `adb logcat -d -s SchoolSync:I` 查看当前系统缓冲区中的同一组事件。跨重启历史以应用内导出的文件为准。

- 旧版课表入口只匹配可见菜单，资料和成绩入口则允许折叠菜单；已统一课表入口的匹配方式，并增加回归检查。
- 同步状态停止原因同时拼入摘要和详情，导致重复显示；已去重。
- 旧版导出仅抓当前 PID 的 logcat，不能保证断线后和重启前的问题仍有记录；已替换为持久化诊断。
- 实机已确认根因：进入「履修登録・登録状況照会」后，学校先要求确认联系方式，页面有「本人連絡先」和「変更なし」，未直接返回课表。点击「変更なし」后立即进入 2026 年 Q3 课表，未修改联系方式。此前日志持续显示已登录，无登录输入框。
- 新增该确认页的严格识别：立即提示「学校要求确认资料」，提供「查看学校网页」入口；避免反复导航和误报登录过期。日后再次出现时由用户核对学校资料，不自动提交个人资料表单。

## 学校日历与教室

- 实机学校日历使用「节次:课程名@地点」，不提供课程代码。现按本账户、本学年度、完整课程名、日期和节次唯一匹配；含糊的同名课程不写入。
- 支持全角数字、体育馆名称，以及「具体教室,遠隔講義」的地点表示。地点和授课方式分开：已核实线上授课时，日历仍显示线上；不会仅因列出教室就判定面授。
- 学校日历的实际逐日安排独立保存，优先于同日的静态校历计划；跨学年只匹配当年课程。没有公布的日期不沿用 2026 年日期推算；尚未核对完整校历的年度不提供完整学季导出。
- 每次前台访问仍查询学校，假期不再跳过教室查询，未公布不会永久关闭重试。新增数据在之后打开应用同步时读取。当前读取学校日历打开的月份及其边界日期，不声称已经获取尚未展示的全年教室。
