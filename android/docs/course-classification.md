# 全学部课程分类

分类适用范围为 App 中的 6 个学部／学环、全部学科，入学课程年度为 2024、2025、2026。课程年度与课表学年度相互独立。

`app/src/main/assets/course-categories.tsv` 保存入学年度、学部、学科、专业方向、课程名称、毕业类别、官方来源 URL、PDF 页码及可用的课程代码和学分。规则包含同一课程在不同年度和方向下的重复适用，不代表不同课程数量。

## 判定顺序

1. 优先采用该学生学校成绩记录中的明确分类或毕业要求外标记。
2. 只在同一入学年度、学部、学科和专业方向内查官方课程表，结合课程代码与学分区分同名课。
3. 共通教育采用官方科目名和科目组对应关系。罗马数字、全半角和空格统一，不把 I 和 II 合并，不进行模糊名称匹配。
4. 预览课程缺少分类时，只复用名称、学分一致且分类唯一的本人历史记录。冲突保留“待分类”。

“待核对”是课表与成绩／学季的对应问题，“待分类”是毕业分类问题，不能混为一谈。分类补全不会增加已修学分或修改 GPA。毕业要求外课程不进入分类进度。

首页分类图与成绩详情使用同一个分类引擎。详情提供分类及官方依据链接。切换学生或课程规则后重新计算，不使用其他学科的默认分类。数学与信息数理、材料与化学生命、电气两方向以及土木与建筑分别判定。

## 数据生成与核验

原始 PDF 放在 `build/curriculum/multi/`。`scripts/repair-curriculum-text.py` 给缺少 ToUnicode 的已知 MS/Meiryo 字体补充映射，生成独立的 `-readable.pdf`，不修改原件。`scripts/build-course-catalog.py` 从官方表格生成 TSV；可指定 `engineering` 等单个学部参数增量重建。表格按真实行边界读取，避免合并单元格造成多个课程串联。

测试包括所有学部／学科／入学年度及可选择方向的数据存在性、跨学科隔离、课程类别的方向差异、学校原分类优先、毕业要求外排除、未知课程保留、同代码多学季预览，以及截图中的共通教育科目。

2026-09-16 全目录回归：59,326 条来源规则，在所有可选专业方向中展开为 62,662 个适用组合，结合代码和学分判定后未分类为 0。报告由单元测试输出到 `app/build/reports/course-classification-audit.tsv`。教育学部资格表中的“共通开设”沿用所属专业类别；明确标注空栏不可履修的班级不作为该专业可选课程。此覆盖结果不包含未公布课程或个人特殊认定。

## 边界

这是一套毕业大类进度与课程分类，不是完整的毕业／教师资格审查。各方向的指定必修、选修组内最低学分、超额学分如何转入自由履修、课程替代和个人认定仍以学校为准。现有模型无法唯一表达的条件或同名冲突继续显示待分类，不用默认专业类别填平缺口。目录覆盖上述官方资料中的课程，不能把尚未公布的新课或个人特批认定宣称为已经核验。

Integrated English 1–3 的 A、B、C、D 均归入英语类别。预览条在没有单独最低学分要求的子分类中也显示已修与预计新增部分；超过最低要求时扩展显示比例，保留虚线新增段，不改变学分要求。
